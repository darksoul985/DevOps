ЗАДАЧА 3
к п. 3
В linux команта Ctrl + c отправляет процессу команду SIGINT, которая заставляет процесс завершиться.
Внутри docker контрейнера всегда есть главный процесс, к которому и происходит подключение через команду docker attach.
Если главный процесс завершается, то завершаются и все остальные подпроцессы запущенные в контенере и он (контейнер) останавливается.
Таким образом, нажатие Ctrl + c при подключении через docker attach заставляет контейнер остановиться.

к п. 10
Внутри контейнера nginx слушает порт 81 после изменения конфигурационного файла, docker контейнер же продолжает транслировать на порт 80.
Таким образом, попытка запросить в запросе `curl http://127.0.0.1:8080` ведет к транслируемому контейнером порту - 80.

к п. 1
Согласно документации `docker compose up` может работать как с файлами compose.yaml/compose.yml, так и с docker-compose.yaml/docker-compose.yml для обратной совместимости.
